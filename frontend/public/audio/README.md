# 音響リソース

このディレクトリには、ゲームで使用する音声ファイルを配置します。

## 必要な音声ファイル

### BGM・環境音

#### S3: 移動指示 + ホラー演出
- **ファイル名**: `horror_ambient.mp3`
- **用途**: ホラー演出時の環境音
- **仕様**:
  - ループ再生
  - 低音の環境音
  - 音量: 30%
  - 時間: 30秒〜1分程度のループ
  - 推奨: 不気味な低音、遠くの足音、風の音など

### SE（効果音）

現在、特定のSEファイルは不要です。ホラー演出は主にビジュアルエフェクトで実現しています。

### VOICEVOX音声

以下の音声はVOICEVOXサーバーで動的に生成されます（`/api/voice/generate`エンドポイント経由）：

#### S1: 1942年パート
- 担当者の台詞（青山龍星(しっとり) - speaker_id: 11）
  - 「ようこそ、赤煉瓦文化館へ。私は本日の担当者でございます。お越しいただき誠にありがとうございます。」
  - 「本日はどのようにしてこちらまでいらっしゃいましたか？」
  - 「なるほど。では、普段はどのようなことをされていますか？」
  - 「ありがとうございます。それでは、まずこの建物でお気に入りの場所を見つけていただきたいと思います。」

## 音声ファイルの配置方法

1. 上記の仕様に合った音声ファイルを用意
2. このディレクトリ（`/public/audio/`）に配置
3. ファイル名は上記の指定通りに

## テスト用の仮ファイル

開発中は無音のMP3ファイルや適当な音声ファイルで代用可能です。

```bash
# 無音のMP3を生成する例（ffmpegを使用）
ffmpeg -f lavfi -i anullsrc=r=44100:cl=mono -t 30 -q:a 9 -acodec libmp3lame horror_ambient.mp3
```

## 注意事項

- 音声ファイルはできるだけ軽量にしてください（目安: 1MB以下）
- フォーマットはMP3を推奨
- ビットレート: 128kbps程度で十分
- サンプリングレート: 44.1kHz推奨
