# 企画書

## タイトル
赤煉瓦文化館 〜こっちにおいで〜  
福岡市赤煉瓦文化館を実空間のまま使う、体験型Webホラーゲーム

## 企画の目的
- 福岡市赤煉瓦文化館（現エンジニアカフェ）の歴史的連続性（1909→資料館→文化館→現在）を「体験」として理解させる
- 恐怖→解放→内省の感情の揺れを使い、プレイヤー自身の「理想」「生きる意義」の記憶を呼び戻す
- 最後に自分のメッセージを刻ませることで、「この建物は受け継がれてきた/自分も受け渡す側になる」という構図を体感させる

※外向け用途は想定しない。開発メンバーが「このゲームは何をしたいか」を共有するための企画書。

## 想定プレイヤー
- エンジニアカフェの来館者
- 赤煉瓦文化館の歴史紹介イベント参加者
- デジタル/ARコンテンツに抵抗のない20〜40代社会人
- 現地プレイが基本だが、撮影がうまく行かない・現地にいない場合でもWeb選択で進行可能

## プレイ時間・運用
- 所要時間：20〜30分（館内移動込み）
- 1セッション有効時間：開始から60分でサーバ側セッション破棄
- 同時接続：標準10人、最大30人を目標（技術的にはECSで水平スケール）

## 全体の体験構成
1. QRコードから起動（URL固定）
2. カメラ/音声許可 → イヤホン着用案内 → 注意書き（ホラー演出あり）
3. 1942年0月0日への時代遡行演出＋担当者との対話（生命保険の診査としての来館）
4. 建物内の5つの「お気に入りの場所」を教えられる（後の探索に必須）
5. 2階の診査室に行くように指示され、途中でホラー演出が入る
6. 診査室での「内省の10問」：子ども時代〜今の願望までを答えさせる（“なし/特にない”は弾く）
7. 診査完了直後、「死亡届が受理されました。7分以内に担当者の存在証明書と交換してください」と通知（1972年0月0日パート）
8. 館内5カ所を7分以内に巡り、各地点で“担当者との記憶のシンクロクイズ”に1回正解してピースを取得（5/5で完成）
9. 2002年0月0日パートで担当者のメッセージを受け取り、自分の「人生の最期に達成したいこと」を一字一句で再現
10. 現在（2025年）に戻り、メインホールのどこに自分のメッセージを残すか選んで終了
11. 入力されたメッセージは次のプレイヤーのどこかで匿名的に使われ、歴史を紡ぐ

## 特徴的な要素
- **舞台固定**：螺旋階段を見上げる場所・暖炉・裏玄関の蝶番・入口エントランス・階上応接室のピアノ・2階診査室は固定で使う（現地調整は不要）
- **音声の動的生成**：VOICEVOX（青山龍星(しっとり)）をEC2上で動作させ、アプリケーションサーバからHTTPで音声を生成する
- **AR的演出**：カメラ映像にホラー用オーバーレイ（影・虚な人）を重ねる。撮影がNGな場面は想定しない（会場に撮影可の掲示あり）
- **匿名継承コンセプト**：過去プレイヤーの回答が匿名化されて次のプレイヤーのクイズのダミーになる。プレイが続くほど“誰かがここで生きた”痕跡が増える

## 使用リソース・権利
- 音声…VOICEVOXで動的生成
- BGM/SE…フリー素材（著作権表示が必要なら表記欄を用意）
- 館の名前・ロゴ・歴史資料…使用前提（現地が既に撮影可なのでゲーム内の撮影説明は省略）

## 表示と言語
- 表示言語：日本語デフォルト、英語は後日追加予定
- 文言はキー化しておく（開発で切り替えできるようにする）
- 年齢制限は行わないが、開始時に「ホラー演出があります・体調に注意してください」は出す
